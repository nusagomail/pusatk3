# Desain: design tokens dan komponen UI dasar (issue #6)

Status: disetujui pemilik, 25 November 2026.

## Maksud

Fondasi tampilan yang konsisten untuk semua halaman: token warna terang/gelap, huruf, dan komponen yang dipakai ulang, sesuai `docs/design-tokens.md` dan mockup.

## Tujuan

- Token CSS terang + gelap (ikut pengaturan perangkat, bisa diganti di header, diingat di peramban).
- Komponen Astro: `Button` (primary/secondary/whatsapp), `Input`, `Select`, `Card`, `VerifiedBadge`, `Pill`, `Header`, `Footer`.
- Aturan: teks di atas oranye navy; kontras ≥ 4.5:1 (dites otomatis); target sentuh ≥ 44 px; footer memuat "Direktori independen, bukan situs pemerintah".
- Halaman contoh internal `/_komponen` (noindex).

## Bukan tujuan

Beranda, cache CDN, SEO, adapter Cloudflare (#5); i18n dan login (tombol ID·EN dan Masuk tampil tanpa fungsi).

## Urutan & konflik

`apps/web` direncanakan di #5, tetapi #6 dikerjakan lebih dulu (disetujui pemilik), jadi #6 membuat kerangka minimal `apps/web`. Kriteria "dipakai di beranda" dipenuhi di #5. Dua warna mockup ditambahkan ke `docs/design-tokens.md`: `--color-accent-soft` `#FDF0E3` dan `--color-accent-text` `#B85F00` (oranye `#E07400` sebagai teks di atas putih kontrasnya < 4.5:1). Mockup memakai garis `#DDE1E7` dan tombol 36 px; dokumen diikuti (`#E3E6EB`, ≥ 44 px).

## Pendekatan

| Pilihan | Keputusan |
| --- | --- |
| A. Komponen Astro tanpa JS (hanya toggle tema berupa skrip kecil) | **Dipilih**: halaman publik cepat; dashboard React kelak memakai token/kelas yang sama |
| B. Komponen React di semua tempat | Ditolak: menambah JS di halaman publik |
| C. `packages/ui` bersama web & mobile | Ditunda: mobile (Expo) tidak bisa memakai komponen Astro; token dipindah ke paket bila mobile dimulai |

## Keputusan builder

- Font: `@fontsource-variable/plus-jakarta-sans` (self-host, tanpa permintaan ke Google).
- Tema: `data-theme` di `<html>`; tanpa pilihan → `prefers-color-scheme`.
- Tes: Vitest + Astro Container API untuk render komponen; kontras dihitung dari `tokens.css`.
