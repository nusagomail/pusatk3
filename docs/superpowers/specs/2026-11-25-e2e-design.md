# Desain: Playwright e2e dasar dan finalisasi CLAUDE.md (#9)

Status: disetujui pemilik (pilihan A) · 25 November 2026

## Tujuan
Menutup Fase 0. Tes browser sungguhan membuktikan bahwa beranda tampil tanpa login, tidak ada error di konsol (termasuk pelanggaran CSP), dan `/api/v1/health` OK. Tes berjalan di setiap PR.

## Pendekatan
- **A (dipilih): lokal, memakai hasil build asli.** Web hasil `astro build` disajikan dengan `wrangler dev -c dist/client/wrangler.json` (workerd, sama seperti di Cloudflare: `_headers`, halaman 404). API memakai `wrangler dev` lokal. Tidak butuh token, jadi bisa jalan di setiap PR.
- B: menguji situs staging. Butuh secret dan baru jalan setelah merge. Uji asap staging sudah ada di `deploy-staging.yml`.
- C: memakai `astro dev`. Hasilnya berbeda dengan yang di-deploy (tanpa CSP build, tanpa `_headers`).

## Rancangan
- `@playwright/test` **1.63.0** (dikunci persis) di root. Versi ini cocok dengan Chromium yang sudah terpasang di sesi cloud, sehingga tidak perlu `playwright install` lokal. Di CI, browser dipasang dengan `playwright install --with-deps chromium`.
- `playwright.config.ts` di root, tes di `e2e/*.spec.ts` (terpisah dari Vitest `tests/**/*.test.ts`).
- `webServer`:
  - API di `127.0.0.1:8787`;
  - web build di `127.0.0.1:4322` (bukan 4321, agar tidak bentrok dengan `astro dev`).
- `pnpm test:e2e` = build web lewat turbo, lalu `playwright test`. Build memakai lingkungan lokal (tanpa `CLOUDFLARE_ENV`), sehingga hasilnya `noindex`.
- Tes:
  - beranda tampil tanpa login (status 200, judul utama terlihat, tidak dialihkan ke halaman masuk);
  - tidak ada `console.error` atau `pageerror`;
  - health menjawab `{status: "ok"}`;
  - path yang tidak ada mendapat 404 dengan halaman 404;
  - header `X-Robots-Tag: noindex` ada pada build non-production.
- CI: job `e2e` terpisah di `ci.yml`, sejajar dengan job pemeriksaan, tanpa secret. Laporan Playwright tidak diunggah, supaya tidak ada action tambahan (lebih sedikit rantai pasok); output konsol `list` sudah cukup.
- `CLAUDE.md` bagian Perintah ditambah `pnpm test:e2e`. `docs/roadmap.md` Fase 0 dicentang, kecuali kriteria "staging menampilkan beranda", yang menunggu environment dan token pemilik.
- ADR 0013.
