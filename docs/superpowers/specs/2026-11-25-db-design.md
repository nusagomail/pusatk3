# Desain: `packages/db` — D1 + Drizzle dan migrasi pertama (issue #4)

Status: disetujui pemilik, 25 November 2026.

## Maksud

Database D1 lewat Drizzle dengan alur migrasi yang aman, tabel referensi pertama, data contoh, dan bukti API bisa membacanya (`GET /api/v1/categories`).

## Tujuan

- Paket `@pusatk3/db`: skema Drizzle `cities`, `course_fields`, `course_categories` sesuai `docs/skema-db.md`.
- Migrasi pertama dibuat `drizzle-kit generate` (hanya `CREATE`), diperiksa manual.
- Seed: 14 bidang + 59 kategori dari `docs/data/kategori-k3.csv`, 8 kota contoh; idempoten (upsert per slug).
- Skrip `pnpm db:generate`, `pnpm db:migrate:local`, `pnpm db:seed:local`.
- `GET /api/v1/categories` (publik, cacheable) membaca D1 lokal.

## Bukan tujuan

D1 staging/production (#7), migrasi remote (#8, CI), sinonim pencarian (Fase 1), endpoint `/cities` (Fase 1).

## Konflik dokumen

Issue #4 menyebut seed kategori dari `docs/glosarium-k3.md`; sumber resmi adalah `docs/data/kategori-k3.csv` (`docs/kategori-k3.md`, `docs/skema-db.md`). CSV diikuti. `course_fields` ikut dibuat karena `course_categories.field_id` merujuknya.

## Pendekatan seed

| Pilihan | Keputusan |
| --- | --- |
| A. Fungsi seed Drizzle (upsert) + skrip lokal via `getPlatformProxy` (wrangler) dijalankan `tsx` | **Dipilih**: tanpa SQL tulisan tangan, fungsi yang sama dipakai tes |
| B. File SQL seed hasil generator + `wrangler d1 execute --file` | Ditolak: SQL dibangun manual |
| C. Data referensi di dalam migrasi | Ditolak: kategori berubah, perlu tinjauan Ahli K3; migrasi untuk struktur |

## Keputusan builder

- `id` ULID teks; `created_at`/`updated_at` integer ms UTC (`timestamp_ms`).
- `issuers` dan `synonyms` kolom teks JSON (array); `issuers` divalidasi `issuerSchema`.
- Masa berlaku CSV: angka di depan (`5 th`, `3 th*`, `3 th (SKP)`) → integer; `—`/`Skema` → null.
- Bidang `sort_order` = urutan kemunculan di CSV.
- Kota contoh: jakarta, surabaya, bekasi, batam, tangerang, karawang, semarang, balikpapan.
- Respons `/categories`: `{ items: [{ slug, name, categories: [{ slug, name, issuers, documentType, typicalValidityYears, regulationRef }] }] }`, `Cache-Control: public, max-age=300, s-maxage=3600, stale-while-revalidate=86400`.
