# Monorepo pnpm + Turborepo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Root workspace with shared TypeScript/ESLint/Prettier/Vitest config and root scripts, no apps yet.

**Architecture:** Shared configs at the repo root; Turborepo orchestrates per-package `build`/`dev`/`typecheck`; lint and test run once from the root and cover every package.

**Tech Stack:** pnpm 10.28, Turborepo 2.11, TypeScript 6.0, ESLint 10 + typescript-eslint 8, Prettier 3, Vitest 4.1, Node 22.

**Spec:** `docs/superpowers/specs/2026-11-24-monorepo-design.md`

## Global Constraints

- Node `>=22.23.4 <23`, `.nvmrc` = `22`; `packageManager` = `pnpm@10.28.0`.
- TypeScript pinned `~6.0.3` (TS 7 unsupported by typescript-eslint and @astrojs/check).
- Every new dependency is dev-only and listed with a reason in the PR.
- Code, names and commits in English.

## Review Focus

- Repo with zero packages: `pnpm build`, `pnpm dev`, `pnpm typecheck`, `pnpm test` must exit 0, not error on "no packages/tests".
- Owner docs (`docs/**/*.md`) must not be reformatted by `prettier --check`/the format hook.
- A future package lacking `typecheck`/`test` scripts must fail the guard test (covered in Task 1).
- Generated folders (`node_modules`, `.turbo`, `dist`, `.astro`, `.wrangler`) must be ignored by ESLint and Prettier.
- Wrong Node major must be rejected at install (`engine-strict`).
