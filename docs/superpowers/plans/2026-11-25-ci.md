# GitHub Actions Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** CI on PRs, automatic staging deploy from main, manual gated production deploy.

**Spec:** `docs/superpowers/specs/2026-11-25-ci-design.md`

## Global Constraints

- `permissions: contents: read` everywhere; secrets only in deploy jobs via environments.
- Every `uses:` pinned to a 40-char SHA; `persist-credentials: false`.
- No secret values echoed; no `pull_request_target`.

## Review Focus

- workflow_run must deploy the exact commit CI tested (head_sha), only for push to main.
- Missing staging secret: skip with notice, not failure; production: hard failure.
- Production preflight cannot be bypassed by workflow inputs.
