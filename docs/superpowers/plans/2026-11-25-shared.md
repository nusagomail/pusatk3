**Goal:** `@pusatk3/shared` with domain constants, API error schema and cursor pagination schema.

**Architecture:** Source-only TS package (`exports` → `src/index.ts`), one file per concern, tests in `packages/shared/test/`.

**Tech Stack:** Zod 4.6, Vitest 4.1, TypeScript 6.0.

**Spec:** `docs/superpowers/specs/2026-11-25-shared-design.md`

## Global Constraints

- Enum values copied verbatim from `docs/skema-db.md`; issuers `kemnaker, bnsp, pupr, esdm, intl`.
- Input schemas are strict (unknown keys rejected).
- Only new runtime dependency: `zod` (reason in PR).

## Review Focus

- `limit` arrives as a query string (`"50"`): must coerce; `"abc"`, `"1.5"`, `"0"`, `"101"`, `""` rejected.
- `cursor=""` rejected rather than treated as "first page" silently.
- Error `message` empty string rejected; unknown `code` rejected.
- Unknown extra keys in error/pagination objects rejected.
- Import from another workspace package (`@pusatk3/shared`) resolves at type-check and runtime.
