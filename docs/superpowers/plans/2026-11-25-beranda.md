# Beranda Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prerendered homepage on the Astro Cloudflare adapter with security/cache headers, SEO and the sections from docs/ui-halaman.md.

**Architecture:** `src/pages/index.astro` composes `src/components/home/*`; static data in `src/data/home.ts`; headers via `public/_headers` (static assets) + Astro `security.csp`; dev-only showcase injected by a tiny integration.

**Tech Stack:** Astro 7.4 + @astrojs/cloudflare 14.4, Vitest, Playwright + Lighthouse (ad hoc).

**Spec:** `docs/superpowers/specs/2026-11-25-beranda-design.md`

## Global Constraints

- No login required; no autoplay; sample schedules always labelled "Contoh tampilan".
- Orange only for primary actions, navy text on orange.
- No MP4 in the bundle.

## Review Focus

- Build output: `/` exists with headers; `/internal/komponen` absent.
- CSP must not break the theme toggle or the inline theme script (no console CSP errors).
- Without `PUBLIC_MEDIA_BASE_URL`: no `<video>`, no VideoObject, no broken play button.
- Mobile 390 px: no horizontal scroll; touch targets ≥ 44 px.
- JSON-LD parses as JSON and has the expected `@type`s.
