# Aset merek PusatK3 (sementara)

Logo konsep **Simpul**: enam titik terhubung ke satu pusat oranye. Aturan lengkap ada di `docs/design-tokens.md`; referensi visual di `docs/mockup/PanduanMerek.dc.html`.

| File | Pakai untuk |
| --- | --- |
| `logo-icon.svg` | Ikon di latar terang |
| `logo-icon-dark.svg` | Ikon di latar gelap |
| `favicon.svg` | Favicon dan ukuran di bawah 32 px (garis lebih tebal) |
| `logo-horizontal.svg` | Header website, latar terang |
| `logo-horizontal-dark.svg` | Header/footer, latar gelap |

Catatan: versi horizontal memakai teks dengan font Plus Jakarta Sans. Logo final (teks diubah jadi outline, plus PNG dan PDF panduan merek) akan diganti setelah difinalisasi desainer.
